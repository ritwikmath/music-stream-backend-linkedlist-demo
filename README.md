# Music App Demo Backend using LinkedList

This application is built to showcase real-life example of using LinkedList for creating a music streaming backend. This application does not include actual streaming responses.

# Create Environment

```bash
python3 -m venv .venv
```

# Activate Virtual Environment

Windows:
```powershell
.\.venv\Scripts\activate
```

Linux:
```bash
. ./.venv/bin/active
```

# Install Dependencies

```bash
pip3 install -r requirements.txt
```

# Run Application

```bash
fastapi dev main.py
```

# Import Postman Collection

Import Music Player.postman_collection.json file into Postman to call the APIs.
